# 슬라임 키우기

쓰다듬어 젤리를 모으고, 먹여서 레벨을 올리고, 레벨이 오르면 젤리가 더 빨리 모이는 방치형(idle) 게임.
의존성 없는 단일 HTML 파일이라 `index.html`을 브라우저로 열면 바로 실행된다.

## 실행

`index.html`을 더블클릭한다. 끝.

저장이 안 된다는 메시지가 뜨면(브라우저가 `file://`에서 localStorage를 막는 경우) 이 폴더에서 로컬 서버를 띄우고 `localhost:8000`으로 접속한다.

```
python -m http.server
```

## 담고 있는 것

방치형 장르의 필수 요소 다섯 개가 모두 들어 있다.

| 시스템 | 구현 |
|---|---|
| 수동 획득 | 슬라임 클릭 |
| 자동 획득 | 젤리밭의 초당 수익 |
| 전투 | 공격력으로 몬스터 자동 사냥, 층이 오를수록 체력 상승 |
| 업그레이드 | 손맛 · 젤리밭 · 소화력 · 힘 훈련 (비용이 지수로 상승) |
| 저장 / 오프라인 보상 | localStorage + 경과 시간 계산, 상한 8시간 |
| 환생(프레스티지) | 레벨 20 이상에서 영혼 획득, 영구 배율 |

핵심 순환은 이렇게 닫힌다.

```
젤리 -> 먹이 -> 레벨 -> 공격력 상승 -> 사냥 가속 -> 젤리
```

## 코드 구조

파일 하나에 다 있고, 주석으로 열 개 구역이 나뉘어 있다. 핵심은 아래 네 층의 단방향 분리다.

- **상태(`state`)** — 저장되어야 하는 값만. 이게 세이브의 전부다.
- **파생 수치(`perClick`, `perSec` …)** — 상태에서 매번 계산하고 **절대 저장하지 않는다.** 저장하면 공식을 바꿀 때 옛 세이브가 틀린 값을 들고 있게 된다.
- **행동(`pat`, `feed`, `buy`, `rebirth`)** — 상태만 바꾸고 화면은 건드리지 않는다.
- **렌더(`render`)** — 상태를 화면에 비추기만 하고 상태를 바꾸지 않는다.

고칠 곳 찾기. 줄 번호는 수정할 때마다 밀리므로 구역 주석으로 찾는다(`Ctrl+F`로 `1.` `2.` 같은 구역 번호 검색).

| 무엇을 바꾸려면 | 어디 |
|---|---|
| 색·글꼴·배치 | `<style>` 블록 |
| 업그레이드 가격·이름·설명 | 구역 1 `UPGRADES` 표 |
| 몬스터 체력·보상 곡선, 몬스터 이름 | 구역 1 `hpOfStage` · `rewardOfStage` · `MONSTERS` |
| 환생 조건, 오프라인 상한, 세이브 키 | 구역 1 하단 상수 |
| 업그레이드의 **실제 효과**, 성장 곡선 | 구역 3 파생 수치 |
| 전투 처리 | 구역 4 `fight` |
| 화면 표시 내용 | 구역 6 `render` |

## 수치 설계

- **업그레이드 비용** = `기본가 × 성장률^보유수`. 성장률 1.15는 쿠키클리커 이후의 사실상 표준값. 크게 잡으면 금방 벽에 막히고, 작게 잡으면 긴장감이 없어진다.
- **레벨업 요구 경험치** = `50 × 레벨^1.6`. 지수가 1보다 크므로 후반이 느려진다.
- **레벨 보상** = 레벨당 획득량 +5%, 곱셈으로 적용되어 클릭·자동 수익·공격력에 동시에 걸린다.
- **몬스터 체력** = `10 × 층^1.55`, **보상** = `8 × 층^1.25`. 체력의 지수가 보상의 지수보다 크므로 층이 오를수록 사냥이 느려지고, 그래서 힘 훈련에 투자할 이유가 생긴다. **이 두 지수의 차이가 전투 난이도 전체를 결정한다.**
- 기본 체력 10과 기본 공격력 2를 맞춰 **첫 몬스터를 5초에** 잡게 했다. 시작 직후 첫 보상이 몇 초 안에 들어오지 않으면 플레이어가 떠난다.

## 업그레이드 추가하기

두 곳을 고쳐야 한다. 표는 가격과 표시만 담당하고, 효과는 파생 수치에 있다.

1. `UPGRADES` 표에 행 추가 (`state.up`의 키는 자동 생성된다)

```js
{ id: 'friend', name: '친구 슬라임', base: 2000, growth: 1.30,
  desc: n => `초당 젤리 +${n * 5}` },
```

2. 효과를 계산식에 반영

```js
const perSec = () => (0.5 * state.up.field + 5 * state.up.friend) * levelMult() * soulMult();
```

## 세이브 다루기

**"고쳤는데 게임이 안 바뀐다"의 원인은 거의 항상 이전 세이브다.**

- 연습 중 초기화 — `F12` → Console에 `localStorage.clear(); location.reload();`
- 밸런스를 크게 뒤엎었을 때 — `SAVE_KEY`의 `v1`을 `v2`로 올린다. 기존 세이브가 무시된다.
- 후반 테스트 — Console에 `state.jelly = 1e9; state.level = 30;`

세이브는 브라우저별·도메인별이다. PC에서 키운 것을 폰에서 이어서 할 수는 없다. 그러려면 서버와 로그인이 필요하다.

## 배포

외부 리소스 참조가 0개인 자기완결 파일이라 어디에 올려도 그대로 동작한다.

- **GitHub Pages** — 무료, 영구 URL, `index.html`을 그대로 서비스하므로 사본이 생기지 않는다.
- **itch.io** — 실제 게임 유통 플랫폼. 방치형을 찾아서 노는 사용자가 모여 있다.
- **Netlify Drop / Cloudflare Pages** — 폴더를 드래그&드롭하면 즉시 URL이 나온다.

배포하면 소스가 100% 공개되고 콘솔로 치트가 가능하다. 싱글플레이라 문제되지 않지만, 랭킹을 넣는다면 서버 검증이 필요해진다.
